## 六、已接受边界（记录）

- 原型 iframe 自导航到外部地址时浏览器仍可能发出请求；平台不承诺阻止内网探测，需在终端/网络层限制测试终端对敏感内网的访问；
- 已加载到浏览器内存/磁盘缓存的内容无法由服务端远程清除；重新访问与后续请求必须失败（no-store 保证）；
- V1 不做病毒扫描（非目标）。
